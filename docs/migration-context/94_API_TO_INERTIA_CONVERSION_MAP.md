## Conversion Principles

- App pages become Inertia web routes with server props.
- Form mutations become Laravel Form Requests submitted through Inertia `useForm`.
- Payment creation/refresh can remain JSON because the UI needs a `snap_redirect_url`.
- Webhooks remain public API routes but must be signed and idempotent.
- Polling endpoints can remain JSON during the first migration but must be scoped by session user/outlet and policies.
- Compatibility API routes may exist temporarily for the old React frontend, but the target Inertia pages should not depend on `.NET` bearer-token plumbing.
